### 3.34 J2 — Inflect 주 개선 실험: 판별기 계승 + 동결 없는 동시 학습 (2026-09-26) — **청취: 불성립(세 문장 중 링잉 낮은 행 2, 0026에서 J2만 '빠지거나 뭉개진 낱말 있음') · 이 묶음 미채택** *(행 안 정정 2026-09-26 — 기록 각주 J2-3: 헤드라인은 "이 페이지 · 세 문장 · 한 런 · 청취자 1인에서 J2 TTS의 링잉 등급이 J1보다 낮은 행 2(0015 3 → 1, 0037 2 → 1) · 높은 행 0, 배포 크기 9,356,513 그대로 + 0026의 '빠지거나 뭉개진 낱말' 회귀(J1 없음 · J2 있음) → 불성립 · 미채택"이다. J2는 링잉 감소 연구 기준으로 보존하고, 다음은 J3다)*

- **사용자 지시 · 리뷰**: 목표는 Inflect의 배포 크기 · 메모리 · 추론 비용을 유지한 채 파인튜닝 품질을 개선하는 것이다. 다른 모델은 원인을 좁히는 비교군이다.
  - J2를 **독립 주 실험**으로 먼저 하고, Style-Bert-VITS2 비교(B2)는 J2를 기다리게 하지 않는 보조 비교로 둔다.
  - 최종 목표는 J2 TTS(J1 대비)로 고정한다. 재구성은 따로 기록하는 중간 성과다.
- **구현 수준 비교**(Inflect J1 대 SBV2 JP-Extra 2.7.0 `d8148f3`): 배포 모델에 영향이 없는 차이 중 이번에 옮긴 것은 둘이다.
  - 판별기: J1은 매 런 새로 초기화하고, SBV2는 사전학습 D를 이어받는다.
  - 적응 일정: J1은 posterior만 → linguistic ×0.5 → decoder ×0.1(3000부터)이고, SBV2는 동결 없이 step 0부터 1e-4다.
  - 남은 후보(미시험): 판별기 갱신 순서(SBV2는 D를 먼저 갱신), posterior 용량, mel 필터(Inflect 자체 HTK · 정규화 없음 대 Slaney), 수치 설정. *(2026-09-27 보완: 판별기 갱신 순서는 J4(§3.36)에서 시험했다.)*
  - 제외(배포 제약): 표본율 · hop · decoder 폭 · BERT.
  - 공통(차이 아님): anti-aliasing 없는 HiFi-GAN V1.
- **J2 설정**: J1 레시피에서 다섯 키를 바꾸고, stage-1 체크포인트에서 `--init-from`으로 생성기와 판별기를 이어받는다.
  - 바뀐 키: warm-up 1500 → 0, 해제 3000 → 0, linguistic 0.5 → 1.0, decoder 0.1 → 1.0, posterior_init은 명목 fresh.
  - 두 차이를 묶은 것으로, 한 옵션 원칙의 **선언된 예외**다(계획 승인).
  - 성공해도 설정에 귀속하지 않는다. 실패하면 "이 묶음 미채택, 각 차이는 미시험"이다.
