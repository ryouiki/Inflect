# Q7 — 일본어 사전학습 기반 강화: 비용 · 실험 설계 (v0.1, 2026-09-30)

> [로드맵 목차](README.md)의 한 부분이다. §8 Q7(J5 뒤 상충 지속으로 등재)의 설계 문서다. **설계만 담는다.** 파일럿을 포함한 모든 실험은 별도 계획과 사용자 승인 뒤에 연다.

## 1. 목표와 제약

- **목표**: 화자 A 일본어 적응 TTS에서 링잉 감소를 지키면서 음높이 · 발음 · 화자를 회복한다. J2–J5는 옵션을 한 가지씩 바꿔 왔다. Q7은 학습에 쓰는 일본어 음성의 양이나 다양성을 늘리는 방향을 검토한다.
- **제약**
  - 배포 모델(Micro, 9,356,513 파라미터)의 구조와 크기를 바꾸지 않는다.
  - 다른 모델로 교체하지 않는다. 다른 모델은 교사나 비교 기준으로만 쓴다.
  - 비공개 연구이고 배포하지 않는다(§8 Q2). 산출물과 교사 합성 자료는 외부에 공개하지 않는다.
  - 판정은 늘 Inflect TTS 청취로 한다. 자동 지표는 붕괴와 심한 내용 손상을 거르는 관문으로만 쓴다.
  - 실험 축과 청취량은 필요한 만큼만 둔다(2026-09-30 사용자 지시).

## 3. 안

### Q7-B 교사 합성 자료 (먼저 검토)

- SBV2 교사로 화자 A 음성을 합성해 Inflect 학습에 쓴다.
- 단일 화자 자료라 툴킷 변경이 없고, 배포 모델도 그대로다.
- 늘어나는 것은 **화자 A 목소리의 발화량**이다. 텍스트 다양성은 아니다. 로컬 텍스트가 JSUT뿐이고, JSUT 텍스트는 stage-1 기반이 이미 JSUT 화자 목소리로 학습했다.
- 위험
  - 교사 특성 전이: 고역 · F0 치우침(자동 서술값), 교사의 운율 습관(메모 "발성이 좀 빠름").
  - 교사는 v2 전사로 학습했다. v3에서 고친 30행의 잘못된 전사–음성 대응이 합성 발음에 옮을 수 있다. 입력 텍스트 기준 CER 거름은 큰 내용 오류만 막는다.
  - 교사의 공식 청취 판정이 미결이고, 교사의 음높이는 청취로 확인한 적이 없다.
  - 라이선스는 비공개 연구에 한정한다.
  - 평가 텍스트 오염은 4절의 제외 규칙으로 막는다.

### Q7-A 일본어 다자료 언어 기반

- C7을 구현하고, 화자 조건 없이 모은 일본어 다자료로 언어 기반을 만든다. 화자 조건을 켜지 않으므로 배포 크기가 유지된다. 그 기반에서 화자 A stage-2를 한다.
- 비용
  - 자료 확보와 라이선스 확인(JVS 등, 로컬에 없음)
  - C7 코드 작업(prepare · audit 역할, 매니페스트)
  - 100–200k step이면 약 9–18 h(3.05 step/s 기준 추정)
- 위험: 화자 평균화, 코드 작업량, 자료 품질 편차.

### Q7-C 교사 유도 손실

- 교사의 길이 · F0 등을 목표로 삼는 손실이다. 학습 코어 코드 비용이 크고 해석 변수가 많아 뒤로 둔다.

## 4. 첫 파일럿 Q7B-1 (설계)

- **교사**: SBV2 화자 A 적응 체크포인트 `G_10000`(§3.37, v2 전사로 학습, sha 고정). 렌더 설정은 §3.37 렌더와 같고, seed는 선택 순번이다.
- **텍스트**: JSUT basic5000 전사에서 2,000문장을 고른다.
  - 제외(문장 부호를 뺀 텍스트 기준)
    - 화자 A 학습 · 검증 텍스트
    - 벤치마크 텍스트
    - 평가 확장(5절) 텍스트
    - 숫자가 든 문장(CER 정규화 문제)
    - JSUT 녹음 길이 1–10초 밖(합성 길이의 대리값)
  - 선택: `sha256("q7b1\0" + 텍스트)` 오름차순으로 앞의 2,000.
- **거름**(사전 선언, 합성 음성마다)
  - Whisper CER ≤ 10 %(입력 텍스트 기준)
  - 길이 0.8–12초
  - 무음 · 포화: `tts_metrics`의 silent · saturated 규칙을 그대로 쓴다
  - 변환 클리핑: `prepare`가 거부하면(C28) 권장 입력 게인을 써서 다시 준비한다
  - 통과율을 기록한다. **통과가 1,000 미만이면 파일럿을 멈추고 보고한다.**
- **자료**: 합성 자료만으로 `prepare`한 별도 자료판이다.
  - 매니페스트: audio, text, `speaker` = 화자 A 가명, `group_id` = 텍스트 해시.
  - 프론트엔드는 `ja-openjtalk`이고 lexicon은 v3와 같은 v2다.
  - 기호표는 v3의 `symbols.json`을 base로 쓰고, 새 기호가 0이어야 한다.
  - 실제 v3와 섞지 않는다. `prepare`는 넣은 모든 행으로 분할을 새로 뽑으므로, 섞으면 v3의 검증셋과 벤치마크 위치가 바뀐다(§4 C30 제안이 다루는 제약).
- **학습(두 단계, 그 밖은 J5a 레시피)**
  1. stage-1 init에서 합성 자료판으로 10,000 step.
  2. 그 체크포인트에서 `--init-from`으로 `ja-spkA-v3`에 10,000 step.
- **대조군: J5a**(stage-1 init에서 v3로 10,000 step, 재사용)
  - 재사용 조건: 자료 sha · seed · 옵션 값이 같고, 그 시점 코드의 기본 경로가 J5a 학습 코드와 같은 계산임을 CPU 검사로 확인한다(J6 §2와 같다).
  - 대조군이 가르지 못하는 것
    - 파일럿은 합성 단계 하나(추가 10,000 step)를 더 거친다. 결론 문장은 "합성 사전 단계를 더한 것"으로 쓰고, 합성 자료 자체의 효과로 귀속하지 않는다.
    - 추가 step만 둔 대조(실제 자료로 10,000 step 더)는 이 파일럿에 넣지 않는다. 파일럿이 유망하면 별도 계획으로 둔다.
    - J5a 트랙은 청취자가 J5 · J6 페이지에서 들은 파일이다.
- **관문 · 판정**: J6 기록 §6의 봉인 문구(결과는 §3.41 예정)를 그대로 옮긴다.
  - 최종 목표(J1 대비)를 먼저 적용한다.
  - 대조군 대비 배치 성공 세 축: 링잉 감소 보존 · 음높이 회복 · 새 낱말 없음.
  - 새 잡음 · 명확한 화자 손상이 있으면 상충 후보로 분리한다.
  - 기준 트랙 문제는 그 축에만 적용한다.
- **실행 규칙**(J6와 같다)
  - 단계별 상한: 합성 · 채점 각 30분, 학습 단계마다 90분, 렌더 · 채점 20분.
  - 기술적 실패(NaN · inf, 상한 초과)는 시간을 예산에 넣고 멈춘 뒤 보고한다.
  - lease · 다른 GPU 작업 가드. 학습은 lease 아래에서 시작하지 않는다.
- **청취**(배치 종료 뒤 한 번, 13클립)
  - 행: 0026 · 0037(같은 문장의 실물 있음, 알려진 문제 문장) + 평가 확장 1행(5절, 참고 음성).
  - 트랙: 실물 또는 참고 음성 · J1 · J5a · 파일럿 + 복제(0026 파일럿).
  - 관문 탈락이면 페이지를 만들지 않는다.
  - 글자는 J6 규칙이다. 이전 페이지와 바이트 동일한 트랙은 받은 글자를 모두 피하고, 단계로 완화한다.
- **비용 추정**(J5 · §3.37 실측 기반)

  | 단계 | 시간 |
  |---|---|
  | 합성 2,000문장 | GPU 약 17분 |
  | 채점(거름) | GPU 약 17분 |
  | `prepare` | CPU 수 분 |
  | 학습 두 단계 | GPU 약 110분 |
  | 렌더 · 관문 | GPU 수 분 |
  | **합계** | **GPU 약 2.5 h** |

  - 디스크는 런 두 개에 약 30 GB, 합성 음성 약 1–2 GB다.
  - **코드 작업**(작업 디렉터리, 추정 반나절–하루)
    - 임의 텍스트용 SBV2 합성 드라이버: 지금 렌더러는 벤치마크 행만 렌더한다.
    - 거름 스크립트.
    - 실물 없는 행의 채점 모드: 지금 `tts_metrics`는 같은 문장의 실물 길이를 읽는다.
    - 페이지 빌더의 행별 안내와 낱말 문항 면제(5절).
    - 파일럿 드라이버와 테스트.

## 5. 평가 확장 (확인 문장 모음)

- 벤치마크에서 청취자가 듣지 않았고 텍스트가 학습에 없는 행은 J6의 0009가 마지막이다. 이후 라운드와 Q7에 쓸 새 확인 문장이 필요하다.
- **설계**
  - **10문장**을 만든다. 라운드마다 새 문장 1개를 쓰는 속도로 약 10라운드분이다.
  - 제외 텍스트: 화자 A 학습 · 검증, JSUT(stage-1 학습), 교사 합성, 벤치마크.
  - 출처는 공개 텍스트 코퍼스나 새로 쓴 문장이다(사용자 결정). 길이는 벤치마크 confirm 중앙값 근처(3–9초 예상)로 한다.
  - 이 행들은 **TTS 전용**이고, **같은 문장의 실물 녹음이 없다.**
- **참고 음성**
  - 페이지에서 그 행의 실물 자리에는 **다른 문장을 읽은 화자 A 녹음**을 두고, **"참고 음성"**으로 명시한다.
  - 참고 음성은 기존 검증 행에서 고르고 고정 규칙으로 정한다. 그 행의 확인 문장과 길이가 가장 가까운, 이전 페이지에 없던 검증 행이다.
  - 내용이 다른 문장이라 청취자는 들으면 참고 음성을 알아볼 수 있다. 그래서 가리지 않고, 안내문에 "이 행의 트랙 중 하나는 다른 문장을 읽은 실제 녹음(참고 음성)입니다"라고 적는다. 어느 글자인지는 알리지 않는다.
  - 참고 음성에는 링잉 · 음높이 · 잡음 · 화자만 묻는다. 낱말 문항은 면제한다. 페이지 빌더에 행별 안내와 문항 면제 기능이 필요하다(4절 코드 작업).
  - 그 행의 기준 트랙 검사는 링잉 · 음높이 · 잡음 · 화자 축만 참고 음성으로 한다. 낱말 축은 그 행에서 판단하지 않는다.
  - 같은 문장의 기준 트랙이 아니므로, 화자 판정은 "같은 사람의 목소리인가"의 참고로만 쓴다.
- **채점**
  - TTS 관문의 CER은 입력 텍스트 기준이라 실물 없이 계산할 수 있다.
  - 지금 도구는 길이 비율을 재려고 실물을 읽으므로, 실물 없는 행의 채점 모드가 필요하다. 그 행에서는 길이 비율 검사를 쓰지 않는다(4절 코드 작업).
